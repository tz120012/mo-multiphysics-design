## 8. 缺口与诚实说明

1. **铜耗预测性**：几何粗估 R_ph（填满/端部）仍显著偏低；本 case 用 Table 10 实测 Rs 覆盖后铜耗与 `3·I²·Rs` 对齐。后续应改进 `_phase_resistance`（线径 Table 9 φ0.64 mm、端部 11.4 mm）方可去掉覆盖做纯预测。
2. **Br 未取自 NC 包**：0.40 T 为铁氧体工程典型；与论文 λpm/E0 在本 MEC+几何映射下自洽（ψ≈0.1147 Wb / E≈48.0 V）。
3. **MEC = SPM 串联路径**：inset/IPM 凸极、漏磁、端部未完整建模；Ld/Lq（本次≈0.037 H）相对 Table 10（0.2055 / 0.3320 H）差距大——**未**纳入本 case 主指标。
4. **carter_factor** 仍默认 1.15；钢牌号 M250-35A 未入材料目录（用通用饱和 μ(B)）。
5. **smoke 10p/12s** 仍独立；本标定**未**用其输出对 0.10 Nm。铜耗公式修正后 smoke Pcu 由 ~60 W → ~120 W（无 golden 锁死）。
