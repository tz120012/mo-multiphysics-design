## 硬约束（拍板前必读）

1. **G3 §6.1 三选一**：①公开文献/教材算例 ②内部台架实测 ③他软件同输入对照；**禁止** fixture 自循环。
2. **现有 smoke fixture ≠ 公开机几何**：
   - 当前 `packages/solver-analytic/smoke/fixtures/radial_pmsm_request.json`：**10 极 / 12 槽**、stack 40 mm、本求解器输出 **T≈4.09 Nm**（报告 tip `6b16c68`）。
   - CREATOR PMSM：**4 极 / 6 槽**、额定约 **0.10 Nm**（2000 rpm）。
   - **选定公开标杆后必须新建/改写 case 几何与工况以匹配标杆**；**不得**拿现 smoke 输出去对 CREATOR 额定转矩；**禁止**自填 golden。
3. **选定已生效**后：可重建几何、引用论文表值写 golden；仍**禁**整包入库 CC BY-NC 数据；仍**禁勾 F1** 直至测复现+Motor 再签；**不开 MVP** 直至 Q5-3+6+7 齐。
4. 发布说明须披露：标定引用公开文献；教学向。
5. heat-proxy FEM **不计**解析 ≤5% 关闭计数。

## 合格判定（任一类型）

| 类型 | 最低证据 | 绑定 case |
| --- | --- | --- |
| ① 公开文献 / 教材算例 | 可追溯题号 / 图表 / DOI（或 ISBN+页）；几何·材料·工况可映射到 case 输入；标杆 torque / copperLoss（或报告约定指标）**非 null** | 优先新建匹配几何的 `rf-pmsm-*`（或改造 smoke-001 输入） |
| ② 内部台架实测 | 台架编号·日期·工况·不确定度；同输入映射；实测扭矩/铜耗表可附 | 同上 |
| ③ 他软件同输入对照 | 软件名+版本；同几何同材料同工况快照；参考输出可复现或截图入库 `docs/qa/reports/refs/` | 同上 |

**不合格（一律拒绝）**：未标定 fixture 自循环、编造精密 golden、heat-proxy / FEM 调度 PASS、口头「量级差不多」、拿现 smoke（10p/12s·T≈4 Nm）对 CREATOR 额定（4p/6s·0.10 Nm）。

## 选用规则

1. **最少关闭径向有效对比意向**：至少 **1** 行候选进入「已采纳」且完成**匹配标杆的 case 几何** + golden 写入 + 相对误差可算（优先 **C-①-01 / A1 CREATOR PMSM**）。
2. 目标覆盖：BLDC/PMSM/ACIM 各 ≥1（AF 后置不挡径向先关）。
3. 采纳后：更新 case `source`、golden 非 null、`pending_calibration` 按报告范围；重出标定报告结论栏；Mo-测试复现 → Motor 方可勾 F1。
4. 本清单**不**授权勾 F1；**不**宣称 MVP；**不**在拍板前写真实 golden。
