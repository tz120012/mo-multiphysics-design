## 选用规则

1. **最少关闭径向有效对比意向**：至少 **1** 行候选进入「已采纳」且完成**匹配标杆的 case 几何** + golden 写入 + 相对误差可算（优先 **C-①-01 / A1 CREATOR PMSM**）。
2. 目标覆盖：BLDC/PMSM/ACIM 各 ≥1（AF 后置不挡径向先关）。
3. 采纳后：更新 case `source`、golden 非 null、`pending_calibration` 按报告范围；重出标定报告结论栏；Mo-测试复现 → Motor 方可勾 F1。
4. 本清单**不**授权勾 F1；**不**宣称 MVP；**不**在拍板前写真实 golden。
