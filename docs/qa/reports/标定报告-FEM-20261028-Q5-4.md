## 2. 标杆来源

### 2.1 一维教材通式（对照，非本轮关闭依据）

| 项 | 内容 |
| --- | --- |
| 公式 | **`Fz = Bg² · A / (2 · μ0)`**，**`Bg = Br · hm / (hm + g · μr_pm)`** |
| 参数 | Br=1.0 T；hm=8 mm；g=1 mm；μr_pm=1.05；A=50×50 mm² → Bg≈0.8840 T；**Fz_1d≈777.29 N** |
| 假设 | 线性不饱和；μ_iron→∞；忽略漏磁/边缘；理想闭磁路 |

### 2.2 书面单指标（本轮关闭依据）

| 项 | 内容 |
| --- | --- |
| 公式 | **`F_ref = [body-rms(Bz_fem)]² · A / (2 · μ0)`**，与 FEM Component Maxwell \|Fz\| 比 |
| 物理依据 | `rms(Bz)² = mean(Bz²)`，与 Maxwell 磁压强 ∝ B² 一致；优于 body-mean（mean(B)² ≠ mean(B²)） |
| 独立性 | 非「用 Fz 反推 Bg 再比 Fz」；Bg 来自气隙 mask 的 SaveScalars **body rms**，力来自 Component nodal/Maxwell |
| 禁止项 | **未**采用 heat-proxy；**未**把 Fz 自循环为 Bg 标杆 |
