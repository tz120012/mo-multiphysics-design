## B. 冻结 IN（可测）

1. **材料步骤可验收**：工作台内区域 → 材料库目录选择/绑定（seed **`mat-*`**）；检视后可进求解；**禁止** `demo-*` / 裸 `Cu` 等别名回潮。
2. **激励步骤可验收**：步骤名「激励」= OP/工况（+可选 drive 草稿）写入 UEM；同壳可读可改。
3. **后处理同壳**：改参→再求解后，结果/场量入口在 Workspace **同工程**可见（可接既有 `/field` 或内嵌）；fixture / heat-proxy 降级须明示；**≠** 磁静力学整机关闭；**禁勾精度**。
4. **参数化 3D 体感抬升**：在 Q6 rebuild 路径上减少「像样例」感（视口反馈、改参可见性）；**仍禁止** fixture 冒充建模完成。

对应产品跟踪项：**Q7-1…Q7-4**；冒烟 **Q7-C1…C5**（见 §C）。

**契约（Motor 开闸）**：**默认零新 API**。主路径 = FE 在 C2 单壳加深 + 既有 `materials` / `jobs(+artifacts)` / `drive` / `geometry.rebuild` / `solver.analytic`。材料另起 REST、后处理改 mems/files、rebuild 改 Jobs/异步几何、新 `/excitation/*`、网格完整向导入 IN —— 须 Motor 另拍板。
