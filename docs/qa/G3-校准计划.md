## 4. 关闭条件

### 4.1 文档债关闭（G3 / Q2-L4）

满足即可将跟踪表中 **G3 / Q2-L4** 标为**已消化（计划正式稿）**：

1. 本正式稿已入库且可被 [Q4plus-验收跟踪](Q4plus-验收跟踪.md) / [Q4plus-冒烟清单](Q4plus-冒烟清单.md) A1/A2 指向。
2. §2 golden 路径表完整（解析首批 3 case + FEM heat-proxy 指针；真值 case 可后置但须书面指向 Q4+-5）。
3. §4.2 / §4.3 关闭条件可对照执行（不必本轮已满足数值关闭）。

> 关闭文档债 **≠** 勾选 ≤5%/≤3%。

### 4.2 解析 ≤5% 数值关闭（标定报告）

须**同时**满足：

1. 至少 **一组**首批解析 case（优先 `rf-pmsm-smoke-001`）完成有效数值对比（标杆非 null；相对误差可计算）。
2. 标杆来源类型 ∈ {公开文献, 内部实测, 他软件}，且 case README / 报告中有可追溯引用。
3. 该组相对误差 ≤ 5%（或报告书面说明单指标覆盖容差及理由）。
4. 存在独立**标定报告**（建议路径 `docs/qa/reports/标定报告-解析-*.md`），结论栏明确「可宣称解析 ≤5%」；Mo-解析确认数值；Mo-产品更新跟踪误差表；**Motor** 在阶段签字材料中确认可勾。
5. 对应 golden 更新为真实值；`pending_calibration` 按报告范围关闭（全局或按 case）。

未满足任一条 → **禁止勾选** Q4+-F1 / 继承清单中的解析 ≤5%。

### 4.3 FEM ≤3% 数值关闭（标定报告）

须**同时**满足：

1. 对照对象为**磁静力学（或任务书认可的 FEM 真值路径）**输出 vs 标杆或 vs 已校准解析——**不得**仅用 heat-proxy 调度成功充当。
2. 至少一组 FEM 数值 case 完成有效对比；相对误差 ≤ 3%（或书面单指标覆盖）。
3. 独立标定报告结论「可宣称 FEM ≤3%」；Mo-有限元确认；产品更新误差表；Motor 确认可勾。
4. heat-proxy 指针 case 可保留作调度回归，但须在报告中标明**不计入** ≤3% 门禁。

未满足 → **禁止勾选** Q4+-F2。

### 4.4 与 MVP 宣称的关系

- Q4+ **全项**经 Motor 分批签字关完后，**方可议**「MVP 已达成」。
- 本计划、任一标定报告关闭、或单轨 ≤5%/≤3% 勾选，**均不自动授权**「MVP 已达成」。

### 6.1 标杆来源类型（解析认）

| 类型 | 是否认作关闭证据 | 备注 |
| --- | --- | --- |
| 公开文献 / 教材算例 | **是** | 须可追溯题号/图表/DOI 或等价；写入 case README + 标定报告 |
| 内部台架实测 | **是** | 须内部编号、工况与测量不确定度说明 |
| 他软件同输入对照 | **是** | 须软件名/版本、同几何同材料同工况快照 |
| 未标定 fixture 自循环 / 编造精密数 | **否** | 不得作 ≤5% 关闭证据 |

**首组意向**：`rf-pmsm-smoke-001` 优先寻找公开或他软件同输入；选定前 `source` 保持 `pending`，golden metrics 保持 `null` + `pending_calibration: true`。
