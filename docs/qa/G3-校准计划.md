## 4. 关闭条件

### 4.1 文档债关闭（G3 / Q2-L4）

满足即可将跟踪表中 **G3 / Q2-L4** 标为**已消化（计划正式稿）**：

1. 本正式稿已入库且可被 [Q4plus-验收跟踪](Q4plus-验收跟踪.md) / [Q4plus-冒烟清单](Q4plus-冒烟清单.md) A1/A2 指向。
2. §2 golden 路径表完整（解析首批径向 3 case + AF 建议项说明 + FEM heat-proxy 指针；真值 case 可后置但须书面指向 Q4+-5）。
3. §4.2 / §4.3 关闭条件可对照执行（不必本轮已满足数值关闭）。

> 关闭文档债 **≠** 勾选 ≤5%/≤3%。Mo-测试 A1/A2 PASS 后产品可将文档债标已消化。

### 4.2 解析 ≤5% 数值关闭（标定报告）

**标杆来源类型（Mo-解析认）**：①公开文献/教材算例 ②内部台架实测 ③他软件同输入对照——三者**任一**合格；**禁止**未标定 fixture 自循环或编造精密 golden。

须**同时**满足：

1. **最少有效对比**：径向 **≥1 组**完整对比（优先 `rf-pmsm-smoke-001`）；目标首批覆盖 BLDC/PMSM/ACIM 各 ≥1；轴向 AF+PMSM **≥1 组**（`af-pmsm-smoke-001`，可后置——**不挡**径向先关 ≤5%，但 G3 **数值整单**关闭前须有）。
2. 每组：标杆非 null；相对误差按指标可算；`toleranceRel` 默认 `0.05`（单指标可覆盖并书面说明）；对比报告入库。
3. 独立**标定报告**（建议 `docs/qa/reports/标定报告-解析-*.md`）结论栏明确「可宣称解析 ≤5%」（可注明径向已关 / 轴向后置范围）。
4. **签字链**：Mo-解析确认算法/入口与报告数值 → Mo-测试确认实跑可复现 → **Motor 书面签字** → 方可允许勾选冒烟 **Q4+-F1**；产品维护关闭条件清单与跟踪误差表。
5. 对应 golden 更新为真实值；`pending_calibration` 按报告范围关闭（全局或按 case）。

未满足任一条 → **禁止勾选** Q4+-F1。

> §4.1 文档债可先关；勾 F1 必须走本节 Motor 签。

### 4.3 FEM ≤3% 数值关闭（标定报告）

须**同时**满足：

1. 对照对象为**磁静力学（或任务书认可的 FEM 真值路径）**输出 vs 标杆或 vs 已校准解析——**不得**仅用 heat-proxy 调度成功充当。
2. 至少一组 FEM 数值 case 完成有效对比；相对误差 ≤ 3%（或书面单指标覆盖）。
3. 独立标定报告结论「可宣称 FEM ≤3%」；Mo-有限元确认；产品更新误差表；Motor 确认可勾。
4. heat-proxy 指针 case 可保留作调度回归，须在报告中标明**不计入** ≤3% 门禁。

未满足 → **禁止勾选** Q4+-F2。

### 4.4 与 MVP 宣称的关系

- Q4+ **全项**经 Motor 分批签字关完后，**方可议**「MVP 已达成」。
- 本计划、任一标定报告关闭、或单轨 ≤5%/≤3% 勾选，**均不自动授权**「MVP 已达成」。
