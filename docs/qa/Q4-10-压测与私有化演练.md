## 4. 遗留：compose Web `:5174`（Q4-C2）

- `.env` 仍 `WEB_HOST_PORT=5174`。

- `GET :5174/api/...` → 超时/失败（box overlay nginx → `host.docker.internal:8000`）。  
- **本轮不修复**；UI/Jobs 冒烟优先 vite `:5173`；私有化验收以 API `:8000/health` + 手册端口表为准。
