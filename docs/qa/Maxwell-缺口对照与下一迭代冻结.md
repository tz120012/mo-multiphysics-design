## A. Maxwell 经典链缺口对照表

摸底来源（只读，2026-10-29）：`docs/01`/`02`/`03`；`docs/qa/` Q4+/Q5 冒烟与 [v1.0.0-发布说明](v1.0.0-发布说明.md)；前端 `apps/web/src/router/index.ts` 与 `views/*`；public `mesh`/`fem` fixture。**材料/激励/网格「待前端确认」已由 Mo-前端复核回写**（产品 2026-10-29）。

硬事实（写入备注，不可外推）：

- MVP / tag **`v1.0.0`** @ tip **`fbb0baa`** 已出口。
- **F1 有限**：仅 `rf-pmsm-creator-001`；**F2 有限**：仅 `ms-gap-force-001` / `ms_gap_force_3d` / body-rms。
- FE `/field` **常有 fixture 降级**（`source=fixture` / `job-fixture`）；**heat-proxy ≠ 磁静力学**。
- 路由为分散页：`/projects`、`/workspace`、`/analytic`、`/axial`、`/field`、`/drive`、`/compare`——**无** Maxwell 式一站式经典链向导（源码可见）。

### 冻结 IN

1. **一站式工作台**：经典链（几何→材料→激励→网格→求解→后处理）可在同一工程内连续走完。  
2. **参数驱动 3D**：真实参数改动能更新几何/视图（不仅切换样例 JSON）。  
3. **改参→求解闭环**：改参后可触发再求解，并看到更新结果或明确状态（非仅静态展示）。  
4. **验收红线**：`workspace` / public fixture **不可再当「建模完成」**（降级须明示，不得口径偷换）。  
5. **验收口径**：体感 / 流程对齐 Maxwell；**不是**「可讲清步骤数」。

对应故事：**US-085**（P0）；原则见 03 §1.1。

## C. 验收标准（产品口径 · 可勾选）

通过条件 = **Maxwell 体感 / 流程对齐**；**≠** 教学步骤数；**≠** 扩大 F1/F2。

- [ ] 从打开工程到后处理，主路径步骤顺序可映射 Maxwell 经典链（几何→材料→激励→网格→求解→后处理），命名可读。
- [ ] 主路径**不依赖**把 workspace / public fixture 当作「建模完成」；若存在降级，UI 明示 fixture/降级且冒烟不得据此勾「建模完成」。
- [ ] 参数修改后，几何或 3D 视图有可见更新（参数驱动，非仅换样例文件）。
- [ ] 参数修改后可触发再求解，并看到作业/解析状态或更新结果（改参→求解闭环可演示）。
- [ ] 同一工程上下文内可连续完成上述链（一站式；允许内部多面板，但不得强迫用户靠「分散页拼凑」才能宣称走通）。
- [ ] 文档与冒烟表述遵守：不扩 MVP；不宣称整机 ≤5%/≤3%；不把 heat-proxy 当磁静力学；不改核心求解算法。
