## 跨阶段通则

1. **冒烟**：每阶段由 **Mo-测试** 出具并维护清单，阶段结束必须实跑；结果附于签字材料。  
2. **签字**：仅 **Motor** 可批准进入下一阶段；签字需日期、阶段编号、遗留项列表。  
3. **变更**：锁定技术栈或 MVP 矩阵变更，须回写 `01` 并重新走不低于当前 Gate 的评审。  
4. **隔离**：只改 `/workspace/mo-platform`；禁止触碰 `low-altitude-platform` 等其他路径。  
5. **误差阈值**：解析 ≤5% / FEM ≤3% 为待校准目标，以标定报告关闭，不作为口头宣称依据。
