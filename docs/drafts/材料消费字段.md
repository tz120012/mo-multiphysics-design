## 1. 读取优先级（钉死）

```text
SolveRequest 内联覆盖 → catalog 项 curves.* → catalog 项 meta → 工程默认
```

内联键允许 snake_case（fixture / 金标）与少量 camelCase 别名；**库内曲线以 `curves` 为目标，`meta` 仅过渡**。

## 2. 目标 `curves`（优先）

| category | 字段 | 说明 |
| --- | --- | --- |
| steel | `bh` / `bp` | CurveTable2D：`points=[[H,B]]` / `[[B,P]]` |
| steel | `lossCoefficients` | `{kH,kE,kExc,freqHz}` |
| magnet | `br_t`, `hc_a_per_m` | SI |
| magnet | `demag[]` | `{temperature_c, curve{points:[[H,B]]}}` |
| magnet | `alphaBr` / `alphaHc` | 温度系数 |
| coil | `resistivity_ohm_m`, `fillFactor`, `skin` | 电阻率优先；σ=1/ρ |
| acim_bar | `conductivity_s_per_m`, `skin` | 导条/端环电导；几何仍归 geometry |

种子 id（不变）：`mat-steel-m19`、`mat-ndfeb-n42`、`mat-copper`、`mat-acim-bar-al` / `mat-acim-bar-cu`、`mat-acim-endring-al`（另有 demo 别名）。

## 3. 过渡 `meta`（仍可读）

| category | 键 |
| --- | --- |
| steel | `bhCurve[{bT,hAPerM}]`、`bpPoints`、`ironLossCoeffs`、`bsT`、`muR` |
| magnet | `brT`、`demagCurve`、`muRec`、`tempCoeffBr` |

旧 snake_case meta（`br_t` / `mur_pm` / `sigma` / `bs_t` / `mur0` / `kh` / `ke`）兼容。

## 4. SolveRequest 消费方式

1. **内联**：`materials.br_t` / `mur_pm` / `sigma_copper` / `sigma_bar` …
2. **id + catalog**：`steel_id` / `magnet_id` / `conductor_id` / `bar_id` + 可选顶层 `materials_catalog`（`{id:item}` 或 `{items:[…]}`，item 可含 `curves`+`meta`）
3. **缺省**：工程默认 + `SolveResult.meta.note` / `materials_sources`

实现：`packages/solver-analytic/materials_adapter.py`；本地 seed 优先读 `apps/api/app/data/materials_seed.json`。
