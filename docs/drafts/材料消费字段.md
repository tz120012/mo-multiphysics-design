## 1. 当前后端 stub

`GET /api/v1/materials` 种子：

| id | category | meta 现状 |
| --- | --- | --- |
| `mat-steel-m19` | steel | `{grade: M19}` |
| `mat-ndfeb-n42` | magnet | `{grade: N42}` |
| `mat-copper` | coil | `{}` |

解析侧本地 seed 在同 id 上补充下列期望键；缺省时用工程默认并写入 `SolveResult.meta.note`。

## 2. 期望 `meta` 键

### steel
| 键 | 类型 | 说明 |
| --- | --- | --- |
| `grade` | string | 牌号（展示） |
| `bs_t` | number | 饱和磁密参考 [T] |
| `mur0` | number | 低场相对磁导率 |
| `kh` | number | Steinmetz 磁滞系数 |
| `ke` | number | 涡流系数 |
| `alpha` | number | 磁滞 B 指数 |

### magnet
| 键 | 类型 | 说明 |
| --- | --- | --- |
| `grade` | string | 牌号 |
| `br_t` | number | 剩磁 [T] |
| `mur_pm` | number | 回复相对磁导率（默认 ~1.05） |

### coil（定子导体）
| 键 | 类型 | 说明 |
| --- | --- | --- |
| `sigma` / `sigma_copper` | number | 电导率 [S/m] |

### bar（ACIM 导条 / 端环粗算）
| 键 | 类型 | 说明 |
| --- | --- | --- |
| `sigma` / `sigma_bar` | number | 导条电导率 [S/m]（铸铝量级 ~3.5e7） |

## 3. SolveRequest 消费方式

1. **内联覆盖**（优先）：`materials.br_t` / `mur_pm` / `sigma_copper` / `sigma_bar` …
2. **id + catalog**：`materials.steel_id` 等 + 可选顶层 `materials_catalog`（`{id: item}` 或 `{items: [...]}`，形状对齐 GET /materials）
3. **缺省**：工程默认 + `meta.note` 说明

本地已知 id 见 `materials_adapter.DEFAULT_MATERIALS_CATALOG`。
