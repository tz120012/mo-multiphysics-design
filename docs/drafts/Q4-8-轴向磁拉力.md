---

## 1. 目标与评估口径

| 量 | 含义 | 交付口径（本轮） |
| --- | --- | --- |
| \(F_z\) / `axialForceN` | 轴向单边磁拉力（N） | 占位 `null` 或 `0` + `pending_calibration` |
| 盘面变形倾向 / `deflectionHintMm` | 简化弯曲给出的位移量级暗示（mm） | 占位；**非**标定变形场 |
| 轴承载荷 / `bearingLoadN` | 重力/预紧 + \(F_z\) 分量合成说明 | 占位；文字口径见 §3 |

不输出原始大场；遵循 F1：manifest + scalars + 禁止默认回传全场。

---

## 2. 方法路径（后置磁静力学）

1. **力**：气隙面 Maxwell 应力张量积分，或虚功/虚位移得轴向力 \(F_z\)。  
2. **变形倾向**：将 \(F_z\)（或分布载荷）作用于简化盘/转子盘弯曲模型 → 中心或关键半径挠度暗示（工程量级，非完整结构 FEM，除非后续单独立项）。  
3. **轴承载荷**：`bearingLoad ≈` 重力分量 + 预紧 + \(F_z\)（及可能的径向分量说明）；符号与坐标与 AF 模板约定一致。

**网格**：可复用 `packages/solver-fem/templates/af_pmsm_3d/`（Gmsh/`mesh.geo`、case 骨架）。**方程**：仍后置磁静力学；当前 heat-proxy **不得**改写成假磁静力学力解。

---

## 3. 现状（无磁静力学）

| 项 | 约定 |
| --- | --- |
| 求解 | 允许 dry-run；不调用假力求解器 |
| 标量 | `axialForceN` / `bearingLoadN` / `deflectionHintMm` = `null` 或 `0` |
| 标志 | `pending_calibration: true` |
| 宣称 | **不宣称**任何精度或「已达 ≤3%」 |

`thinning.py` 可在 `scalars.json` 中默认写出上述占位键，避免消费方缺字段；数值不得伪装为已校准结果。
