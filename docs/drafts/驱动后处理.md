## 4. 共性能力清单

1. **PWM**：载波频率、调制比、调制方式（占位：SPWM/SVPWM 命名预留，Q4 定默认）。  
2. **死区**：死区时间对相电流畸变、平均转矩与脉动的影响（工程模型，非全开关电路仿真）。  
3. **效率 Map**：转矩–转速平面扫描；点内效率 = 输出机械功率 / 输入电功率；缓存入 `.mems` `results/`。  
4. **转矩脉动**：周期内 ripple 指标（峰峰值、THD 类指标待 Q4 与测试对齐）。  
5. **损耗分离**：铁损、铜损、永磁涡流（若适用）、导条/端环（ACIM）。  
6. **退磁**：高温/过载工作点相对退磁曲线裕度（永磁机型）。  
7. **导条温升**：ACIM 导条/端环损耗 → 温升评估（可与 LPTN 迭代衔接）。
