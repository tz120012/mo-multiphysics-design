## 2. 真值路径（AF 简化磁静力学盒）

### 2.1 几何 / 网格

`packages/solver-fem/templates/af_pmsm_3d_ms/mesh.geo`

- 沿 Z 三层：`coil_pm`（体 1）+ `airgap`（体 2）+ `iron`（体 3）
- 外表面 Physical `exterior` → Dirichlet `AV {e}=0`
- **简化**：非完整 AF 电机拓扑；用于方程 + 后处理冒烟，**非**标定几何

### 2.2 Elmer case

`packages/solver-fem/templates/af_pmsm_3d_ms/case.sif`（**可执行**，非全注释骨架）

| 步骤 | 模块 |
| --- | --- |
| 磁静力学 | `MagnetoDynamics` / **`WhitneyAVSolver`**（edge basis） |
| 场量 | **`MagnetoDynamicsCalcFields`**：B、H、**Calculate Nodal Forces**、**Calculate Maxwell Stress** |
| 激励 | 体 1 均匀 `Current Density 1`（简化；非绕组/永磁标定） |
| 力 | `Component` iron_target：`Calculate Magnetic Force = True` |
| 写出 | `SaveData` / `SaveScalars` → `scalars.dat`（含 magnetic force 1/2/3） |

镜像：`elmerfem-csc`（Elmer **v26.2**）含 `MagnetoDynamics.so`；**不加 GetDP / 新 profile**。

### 2.3 后处理 → `axialForceN`

`packages/solver-fem/postprocess_ms.py`

1. 读 `scalars.dat` + `scalars.dat.names`
2. 列 `component 1: res: magnetic force 3` → **`axialForceN`（Fz）**
3. 同源：`forceXN` / `forceYN`、`magneticEnergyJ`
4. `postprocess: "maxwell"`（nodal / Maxwell 磁力；非虚功本轮默认）
5. 写入 `results/fem/{jobId}/scalars.json` + manifest；**禁止**用 heat-proxy 温度冒充力
6. 数值未与标杆对比 → **`pending_calibration: true`** + notes 标明未校准

### 2.4 Runner

`packages/solver-fem/run_job.py`

- `equationMode=magnetostatic` + `MO_FEM_DRY_RUN=0`：走真路径 + 后处理（不再因 PathReady=false 直接拒绝；模板已 `true`）
- heat-proxy 旧路径不变
