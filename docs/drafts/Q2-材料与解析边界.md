## 2. Materials API（Q2-1）

### 2.1 类别枚举

与现有 OpenAPI stub 用语一致：

```text
steel | magnet | coil | acim_bar
```

### 2.2 读写策略

| 种类 | 行为 |
| --- | --- |
| **Built-in seed** | 只读：`GET /materials`、`GET /materials/{id}`；禁止客户端改写（PUT/DELETE → 403 或 409） |
| **Custom** | 可变：`POST /materials` 创建；`PUT /materials/{id}` 全量替换；`DELETE`（允许 soft-delete） |
| **PATCH** | Q2 **可选**；优先 PUT |

### 2.3 载荷：类型化曲线（不得仅靠自由 `meta`）

| category | 必填/核心字段 | 单位约定（草案） |
| --- | --- | --- |
| `steel` | `curves.bh` 与/或 `curves.bp` 表；可选 `lossCoefficients`（Steinmetz / Bertotti 粗系数） | B: T；H: A/m；P: W/kg；f 参考 Hz 写入曲线 meta |
| `magnet` | `curves.demag`（≥1 条，可多温度）；`br_t`、`hc_a_per_m`；可选温度系数 `alphaBr` / `alphaHc` | Br: T；Hc: A/m；温度: °C |
| `coil` | `resistivity_ohm_m`；`fillFactor` 默认；可选 skin 参数 | Ω·m；fillFactor 无量纲 0–1 |
| `acim_bar` | `conductivity_s_per_m`；可选 skin-effect 参数 | S/m；**导条几何留在 geometry / `.mems` geometry** — 材料仅电/热物性 |

公共字段：`id`、`name`、`category`、`builtin`（bool）、`materialsSchemaVersion`、`deletedAt`（soft-delete）、可选 `meta`（扩展，不得替代类型化曲线）。

**版本钉死：** `materialsSchemaVersion: "0.1.0-q2"`（Material 资源与种子均携带）。**不** bump `.mems` / mems 包到 `1.0.0`（仍 `1.0.0-draft`，待 Motor 钉 pin）。

### 2.4 `.mems` `materials/` 与 API 库同步

- `.mems` `materials/`：**仅 refs + 工程覆盖（overrides）**；完整库在 API DB。
- FE / solver 解析：`materialId` → API GET（或包内 embedded override）。
- 自定义材料创建后，工程可把 id 写入 `materials/refs.json`（命名示意）；覆盖曲线可放 `materials/custom/`。

### 2.5 验收条（Materials）

| 角色 | Accept bar |
| --- | --- |
| **Mo-后端** | 四类种子可 list/get；custom POST/PUT/DELETE；builtin 不可写；响应含 `materialsSchemaVersion` |
| **Mo-前端** | 选型 UI 走 list/get；自定义材料走 POST/PUT；求解前 resolve id→曲线 |
| **Mo-解析** | SolveRequest 可消费 API 曲线或 override；不自建材料 DB |
| **Mo-测试** | 种子 + CRUD 冒烟；builtin 写拒绝 |

## 3. Analytic 双轨（Q2-2 / Q2-6）— 客户端优先

### 3.1 路径

| 路径 | 用途 | 机制 |
| --- | --- | --- |
| **交互（主路径）** | UI 秒级试算 | FE 跑 **Wasm**；Q2 早期可用可选同步 Python 轻量端。**禁止**阻塞 UI 于 Jobs HTTP 轮询（精神同 Q1-6 history local-first） |
| **批处理 / Benchmark（可选 Q2-6）** | 长任务、对标批跑 | `POST /jobs` `jobType=analytic` → Celery → `GET /jobs/{id}`；结果快照写入 `.mems` `solver/analytic/`（经 mems PUT 或 Job `resultRef`） |
| **可选同步端（Q2 stub）** | Bot / CI / Wasm 未就绪时的 FE 降级 | `POST /solver/analytic/solve` — 轻量 Python 包装 `packages/solver-analytic`；**非 MVP 阻塞**若 Wasm 先到 |

**不要求**服务端托管唯一求解内核。

### 3.2 共享契约

- 真理源：`packages/solver-analytic/api/solve.schema.json`（SolveRequest / SolveResult）。
- OpenAPI `AnalyticSolveRequest` / `AnalyticSolveResult` **镜像**该 schema（或文档声明 `$ref` 对齐）；**禁止** FE 另起 DTO。
- 求解后：FE 或 worker 写入 `.mems` `solver/analytic/`（见 §5）；快照内注明 `schemaVersion`（与 solve schema 对齐；Q2 可沿用 / 轻 bump 至 `0.1.0-q2`，由 Mo-解析提 MR，架构确认）。

### 3.3 降级顺序（FE）

```text
1. Wasm（browser）
2. 可选 sync POST /solver/analytic/solve
3. Jobs analytic（Celery）
```

### 3.4 验收条（Analytic）

| 角色 | Accept bar |
| --- | --- |
| **Mo-前端** | 交互路径不依赖 Jobs；Wasm 不可用时按降级序；快照可 PUT 回 mems |
| **Mo-解析** | Python 金标 + Wasm 同 JSON 契约；径向 MEC + ACIM 电路 Q2 特征完备；轴向多平面保持 Q3 stub |
| **Mo-后端** | Jobs analytic 可入队/轮询（Q2-6）；可选 sync 端薄包装（推荐 stub）；不实现 MEC 数学 |
| **Mo-测试** | 回归对 Python 金标；smoke 覆盖 Wasm 或 sync 至少一条路径 |

## 4. Wasm 部署形态（Q2 语言裁决）

### 4.1 语言

| 裁决 | 说明 |
| --- | --- |
| **Prefer Rust → wasm32** | `wasm-pack` / `wasm-bindgen`；浏览器包建议路径 `packages/solver-analytic-wasm/`（或 `packages/solver-wasm/`） |
| **Python 保留** | `packages/solver-analytic` = **参考 / 金标 / CI** |
| **C++** | **延期**。树内无 C++ 解析内核 → Q2 **钉 Rust**（关闭 解析范围「Rust vs C++」开放项） |

### 4.2 交付

| 项 | 口径 |
| --- | --- |
| 形态 | npm 可消费的 Wasm glue，供 `apps/web` 使用 |
| 产物 | **推荐 CI/build 生成**；Q2 草案**不**建议提交大型二进制 |
| 特征完备 | 径向 MEC（BLDC/PMSM）+ ACIM 等效电路；轴向多平面 → Q3 stub |
| API 表面 | 同 SolveRequest/SolveResult JSON（UTF-8）进出；无分叉 FE DTO |

## 附录 A — `geometrySummary` 字段钉表（草案）

来源对照：`packages/solver-analytic/api/solve.schema.json` `$defs.GeometrySummary` + `packages/geometry` 径向参数（`mo_geometry.radial`）。

**所有权建议：** Mo-几何提供 `export_geometry_summary(params) → GeometrySummary`；Mo-解析只消费；Mo-架构维护本表。

### A.1 必填（与现 schema 对齐）

| Solve 字段 | 单位 | 几何源（示意映射） |
| --- | --- | --- |
| `poles` | — | `rotor.poleCount`（极数；极对数 = poles/2） |
| `slots` | — | `stator.slotCount` |
| `stack_length_m` | m | `stator.stackLength` 或 `axialActiveLength`（mm→m） |
| `airgap_m` | m | `airgap` |
| `rotor_od_m` | m | `rotor.outerDiameter` |
| `stator_id_m` | m | `stator.innerDiameter` |

### A.2 可选（MEC 已消费 / 有默认）

| Solve 字段 | 单位 | 几何源 / 备注 |
| --- | --- | --- |
| `magnet_thickness_m` | m | 磁钢厚度（几何扩展或估算） |
| `turns_per_phase` | — | 绕组；几何/驱动侧可后置 |
| `magnet_arc_ratio` | — | 默认 0.7 |
| `carter_factor` | — | 默认 1.15 |
| `tooth_height_m` | m | 可由 `stator` 齿高导出；缺省则 MEC 估算 |
| `stator_yoke_height_m` | m | `stator.yokeHeight` |
| `rotor_yoke_height_m` | m | 几何扩展或估算 |
| `winding_factor` | — | 默认 0.93 |
| `stator_od_m` | m | **建议 Q2 增补**：`stator.outerDiameter` → 减少齿/轭估算歧义（开放：是否 bump solve schema） |

> 命名风格：solve schema 现为 **snake_case + SI 米**；geometry 包为 **camelCase + mm**。导出层负责换算与改名，**禁止**双写冲突源进 `.mems` geometry。
