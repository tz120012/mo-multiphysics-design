## 2. 输入契约（解析适配层）

### 2.1 权威损耗形（FEM tip `864ec20` — 强制）

见 [Q4-7-热闭环-FEM损耗输入.md](./Q4-7-热闭环-FEM损耗输入.md) §2 与 fixture `q4_thermal_loss_contract.json`：

```json
{
  "schemaVersion": "fem-scalars-v0",
  "pending_calibration": true,
  "lossesW": {
    "total": null,
    "iron": null,
    "copper": null,
    "pmEddy": null,
    "rotorBar": null,
    "endRing": null
  },
  "lossBreakdown": { "source": "analytic", "unit": "W", "notes": "..." },
  "operatingPoint": { "rpm": 3000, "torqueNm": null, "T_ambientC": 25 },
  "source": "analytic",
  "jobId": "...",
  "resultRef": "solver/fem/jobs/.../manifest.json"
}
```

| 字段 | 说明 |
| --- | --- |
| `lossesW` | 分项 W；键名锁定：`total`/`iron`/`copper`/`pmEddy`/`rotorBar`/`endRing` |
| `lossBreakdown` | 可选元数据；MVP 透传 |
| `operatingPoint` | `rpm` / `torqueNm` / `T_ambientC` |
| `source` | ∈ `{fem, analytic, drive}` |
| `jobId` / `resultRef` | F1 / Jobs 指针；可空 |
| `pending_calibration` | 输入可带；**输出恒 true**（本阶段） |

解析自产损耗 → `source=analytic`。heat-proxy 标量走 F1 manifest，**禁止**当作 LPTN `tempsOut`。

### 2.2 驱动别名映射（适配层 only）

驱动 Q4-6 入参可带 camelCase 别名；**归一化为 §2.1 后再算**：

| 驱动别名 | 权威键 |
| --- | --- |
| `lossesW.bar` | `lossesW.rotorBar` |
| `lossesW.magnetEddy` | `lossesW.pmEddy` |
| `operatingPoint.speedRpm` | `operatingPoint.rpm` |
| `operatingPoint.tempC` | 材料/磁体温度假设（退磁）；环境温用 `T_ambientC` |
| `machineType` | `machine_type`（内核） |

### 3.3 LPTN 迭代记录（Q4-7 — `thermal-loop-iter-v0`）

**强制**对齐 FEM §4：

```json
{
  "schemaVersion": "thermal-loop-iter-v0",
  "pending_calibration": true,
  "source": "analytic",
  "jobId": null,
  "resultRef": null,
  "lossBreakdown": null,
  "lossesW": {
    "total": 125.0,
    "iron": 40.0,
    "copper": 80.0,
    "pmEddy": 5.0,
    "rotorBar": null,
    "endRing": null
  },
  "meta": {
    "solver": "lptn_loop",
    "source": "analytic",
    "pending_calibration": true,
    "converged": true,
    "elapsed_ms": 0.0,
    "mock": false
  },
  "iters": [
    {
      "iter": 0,
      "lossesIn": { "source": "analytic", "lossesW": { "iron": 40.0, "copper": 80.0, "pmEddy": 5.0 } },
      "tempsOut": { "windingC": 95.0, "magnetC": 88.0, "ambientC": 25.0 },
      "materialUpdate": { "BrFactor": 0.95, "resistivityFactor": 1.22 },
      "residual": 0.012
    }
  ],
  "fem_compare_hook": null
}
```

| 键 | 含义 |
| --- | --- |
| `iters[].lossesIn` | 本轮注入；含 `source` + `lossesW`（权威键） |
| `iters[].tempsOut` | **仅** LPTN：`windingC` / `magnetC` / `ambientC`（≠ heat-proxy） |
| `iters[].materialUpdate` | `BrFactor` / `resistivityFactor` |
| `iters[].residual` | 收敛标量；未算可为 `null` |
| `meta.converged` | 闭环是否收敛 |

内部节点可有 copper/iron/magnet_or_bar；对外 `tempsOut` 映射为 windingC≈copper、magnetC≈magnet_or_bar。

## 4. MVP 范围与局限

| 项 | MVP | 局限 |
| --- | --- | --- |
| 退磁 | 线性温漂 + 单膝点；负载线或给定 B | 无完整 BH 族；`pending_calibration` |
| 导条温升 | \(ΔT=P·R_\mathrm{th}\) | 无槽内二维热；工程默认 Rth |
| LPTN | 少节点稳态迭代；温漂→损耗缩放 / 可选 `solve()` | 非标定热容热导；不接 Elmer |
| 字段 | 强制 FEM 权威名 + 驱动别名映射 | 不自创 `lossesW` 键 |
| 精度 | — | **不宣称 ≤5%**；无伪造 FEM 金标 |
