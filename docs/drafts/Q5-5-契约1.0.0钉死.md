## 2. 兼容与破坏性

### 2.1 相对 Q1 草案的核对结论（`rg` / `git log`）

相对初稿 tip `c0e9a94` 以降：`mems-schema-v1.md` / `openapi-v1.yaml` 演进主要为 **文档细化、Jobs/artifacts 注记、材料/几何双轨说明、poleCount 命名澄清**；**未见**删除/重命名整包必填字段、更改顶层 zip 布局、或更改 `memsSchemaVersion` 枚举语义（值始终为 `1.0.0-draft`）。

| 检查项 | 结论 |
| --- | --- |
| 删除/重命名必填（整包顶层） | **无** |
| 枚举语义变更（`memsSchemaVersion`） | **无**（仅去 `-draft` 后缀） |
| 顶层布局变更（zip 根成员约定） | **无** |

→ 视为 **兼容升格**（去掉 `-draft`）。

### 2.2 破坏性变更清单

**无（兼容升格）。**

若后续实现 tip 发现真实破坏点，须在本文件 §9 修订表追加迁移说明，并评估是否仍可称兼容升格。

### 2.3 旧客户端仍发 `1.0.0-draft`

| 方向 | 行为 |
| --- | --- |

| **写 / 新建产出** | **只产出** `1.0.0` |
