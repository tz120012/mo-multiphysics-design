## 1. 角色边界

**负责：**

- 径向（RF）/ 轴向（AF）参数化几何引擎（槽、齿、轭、磁钢拓扑；盘式内外径/盘数等）
- ACIM 导条几何与相关参数位（槽形、导条截面、端环）为一等参数
- CAD 导出：STEP / DXF
- 与 Mo-前端协作：几何参数 → Three.js 可调参刷新

**不负责（协作接口）：**

- 账号/项目 CRUD、`.mems` schema 定稿 → Mo-架构 / Mo-后端
- 解析 MEC / 多平面 / 等效电路 → Mo-解析
- FEM 网格与求解 → Mo-有限元
- 驱动与后处理 → Mo-驱动
- 材料库服务实现 → Mo-解析 / Mo-后端（几何侧仅引用材料 ID）

**隔离：** 仅改 `/workspace/mo-platform`；禁止触碰 `low-altitude-platform` 等。

## 4. 参数族提纲（草案，非最终 schema）

### 4.1 径向 RF（共性）

- 拓扑：内转子 / 外转子
- 定子：内外径、叠长、槽数、槽形（直/斜/扇形）、齿宽、轭高、斜槽角（可选）
- 转子：内外径、磁钢拓扑（表贴/内置等占位枚举）、极数
- 气隙、轴向有效长度、单位制

### 4.2 径向 ACIM 增量

- 导条槽形与导条截面、端环截面/电阻率材料引用
- 笼型极对数与槽配合约束（校验规则占位）

### 4.3 轴向 AF

- 构型：RFMR（单定双转）/ FRMF（双定单转）
- 内外径、盘数、气隙、盘厚、磁钢扇区角、槽/极参数

### 4.4 导出

- STEP：装配级实体（定子/转子/磁钢/导条等部件可选分层）
- DXF：2D 截面（径向）或展开/关键截面（轴向策略待定）
