## 3. 同工程闭环目标数据流（解析视角）

```text
UEM / .mems geometry.params
    → geometry.rebuild_live / export_geometry_summary  → GeometrySummary
    → (+ UEM.materials + UEM.operatingPoint)
    → compose_solve_request 或 FE 等价组装
    → solve() | POST /solver/analytic/solve | Wasm
    → UEM.results.analytic（只读投影）
    → 可选 analyticSnapshot → PUT mems `solver/analytic/`（显式保存）
```

原则：

- **几何真相**在 mems / UEM；解析**不**维护第二套页面私有几何。
- 视口 debounce rebuild **≠** 自动 FEM/analytic；求解须**显式按钮/菜单**。
- AF：可继续用 `export_axial_pipeline_entry.analyticSolveStub` 填材料/工况后再 POST。
- RF：`rebuild_live_geometry` 已给 `geometrySummary`；stub 可由 `compose_solve_request` 组装（几何包 RF 未附 `analyticSolveStub` 非阻塞）。

### 5.3 接口契约（最小）

**请求（已存在）：** `SolveRequest`（`schema_version=0.0.0-gate0`）

```json
{
  "schema_version": "0.0.0-gate0",
  "topology": "RF",
  "machine_type": "PMSM",
  "geometry": { "poles": 10, "slots": 12, "stack_length_m": 0.04, "airgap_m": 0.0008, "rotor_od_m": 0.06, "stator_id_m": 0.0616 },
  "materials": { "br_t": 1.2 },
  "operating_point": { "speed_rpm": 3000, "current_a_peak": 25, "gamma_deg": 0 }
}
```

**HTTP：** `POST /api/v1/solver/analytic/solve?solver=mec` + Bearer；body = 上式。

**组装（Python）：**

```python
from compose_request import compose_solve_request
from solve import solve
req = compose_solve_request(
    topology="RF", machine_type="PMSM",
    geometry=geometry_summary, materials=materials, operating_point=op,
)
result = solve(req, solver="mec")
```

**FE 等价：** 用 UEM 切片填 `SolveRequest`，再 `solveRadial(req)`（降级序不变）。
