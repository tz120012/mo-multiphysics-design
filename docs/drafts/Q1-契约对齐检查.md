## 结论

**部分对齐，Q1 契约路径仍大量缺失。**

- **后端（apps/api）**：仅落地 `/health`（根路径）与 `/api/v1/projects` CRUD 壳；**无** `/auth/*`、**无** mems get/put/import/export、**无** history undo/redo。`memsSchemaVersion` 默认值为 **`0.1.0-draft`**，与契约 **`1.0.0-draft`** 不一致。项目更新为 **PATCH**，契约为 **PUT**。
- **前端（apps/web）**：已有对齐契约的手写类型与 API 函数壳（`src/api/types.ts` / `auth.ts` / `projects.ts`），`MEMS_SCHEMA_VERSION = "1.0.0-draft"`；但函数一律 `not wired`，登录/列表仍用 localStorage + 假数据。**属壳阶段可接受**，尚未接真 API。
- **样例 `.mems` 包（Q1-2）**：**尚不存在**；等待 Q1-2 补齐后钉 `1.0.0`（可去掉 `-draft`）。

契约注明 Gate0/早 Q1 路由可先 501/空壳——当前后端是「路径未挂载」，不是「已挂载返回 501」。
