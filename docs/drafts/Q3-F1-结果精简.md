## 1. 原则（复述 §5.1 / F1）

1. **默认禁止**把全网格 / 全场体积（VTK/VTU/原始 Elmer `.result` 等）灌进浏览器默认路径。
2. Worker 只保证写出：**索引 manifest** + **精简产物**；全场可留在 `MO_FEM_WORKDIR/jobs/{id}/solve/`（worker 盘），不进默认 mems 浏览器路径。
3. FE（`/field` / Q3-6）**只消费**精简产物；Jobs 通过 `resultRef` 指向 manifest。
4. 单作业浏览器路径合计软顶 **~5–20 MB**（§5.5）；超顶降采样 / 少切片，勿把全场塞进 zip。

---

## 2. 路径与 `resultRef`

| 路径（相对 `.mems` 根 / `MO_FEM_WORKDIR`） | 角色 |
| --- | --- |
| `solver/fem/jobs/{jobId}/manifest.json` | 作业索引：状态、内核、维度、标量摘要、`artifacts[]` |
| `results/fem/{jobId}/scalars.json` | 关键标量 JSON（`role=scalars`） |
| `results/fem/{jobId}/slice.gltf` | 切片/表面 glTF（`role=slice`；亦可 `surface`+glb） |
| `results/fem/{jobId}/preview.png` | 预览图（`role=preview`） |

**Jobs 合同**：`GET /api/v1/jobs/{id}` 成功时

```text
resultRef = "solver/fem/jobs/{jobId}/manifest.json"
```

前端或 mems 客户端：读 `resultRef` → 解析 `artifacts[].path` → 拉取精简件。  
**不要**把 `jobs/{id}/solve/mesh/*.vtu` 当作 `/field` 默认输入。

## 3. `packages/solver-fem/thinning.py` 职责

| 函数 | 职责 |
| --- | --- |
| `write_result_artifacts(...)` | 写出 manifest + `scalars.json` + stub/复制 `slice.gltf` + `preview.png`；填充 `artifacts[]` 与 `scalars.dryRun` / `pending_calibration` |
| `write_dry_run_artifacts(...)` | 兼容封装：`dry_run=True` 调用上面 |

**不做**：网格生成、ElmerSolver 调用、VTK→glTF 真场转换（磁静力学场后处理后置）。  
**调用方**：`run_job.py`（dry-run 与 heat-proxy 成功后均写精简件）；Celery `app.tasks.fem` 经 `run_job` 间接触发。

写盘根：`MO_FEM_WORKDIR`（compose 默认 `/var/mo/fem`），布局与 `.mems` 内相对路径一致，便于同步进工程包。

## 4. manifest / scalars 最小约定（与 schema / §5.3 对齐）

### 4.1 `manifest.json`

必填：`jobId`, `status`, `solverKernel`, `topology`, `machineType`, `dim`, `scalars`, `artifacts`  
常用附加：`createdAt`, `updatedAt`, `notes`

`artifacts[]` 元素：`{ path, role, format, bytes? }`  
`role` ∈ `scalars` \| `slice` \| `surface` \| `preview` \| `other`  
`format` ∈ `json` \| `gltf` \| `glb` \| `png` \| `webp` \| `other`

### 4.2 `manifest.scalars`（列表 UI / 对照）

| 键 | Q3 现状 |
| --- | --- |
| `torqueNm` | 占位 `0.0`（heat-proxy / dry-run **非**标定转矩） |
| `dryRun` | `true` = 未调 Elmer；`false` = 已调 ElmerSolver（仍可能是 heat-proxy） |
| `pending_calibration` | 恒 `true`（未宣称 ≤3%） |
| `elmerExit` | 仅真跑时出现；`0` = ElmerSolver 退出成功 |

### 4.3 `results/.../scalars.json`

```json
{
  "schemaVersion": "fem-scalars-v0",
  "torqueNm": 0.0,
  "dryRun": false,
  "pending_calibration": true,
  "notes": "…",
  "inputEcho": { "topology": "RF", "machineType": "PMSM", "dim": "2d", "…" : "…" }
}
```

## 5. `/field` 最小可消费产物（dry-run / heat-proxy 共用）

前端 `FieldVizView`（Q3-6）当前 fixture 基路径：

```text
/fem/rf_pmsm_2d_dryrun/   ← apps/web public；同源自 packages/solver-fem/fixtures/rf_pmsm_2d_dryrun/
```

**最小集合（三件套 + manifest）**：

| 文件 | 用途 |
| --- | --- |
| `manifest.json` | 元数据 + `artifacts` 清单 |
| `scalars.json` | 标量表（亦可先读 `manifest.scalars`） |
| `slice.gltf` | Three.js 切片网格 |
| `preview.png` | 侧栏/缩略预览 |

加载顺序建议：`manifest` → 按 `artifacts` 拉 `scalars` / `slice` / `preview`。  
路径解析：`artifacts.path` 为 `.mems` 相对路径；fixture 场景可用 basename 映射到同级目录（前端 tip 已如此处理）。

**样例指针（仓库内）**：

- Fixture 目录：`packages/solver-fem/fixtures/rf_pmsm_2d_dryrun/{manifest,scalars,slice,preview}.*`
- Schema：`packages/solver-fem/api/fem-manifest.schema.json`
- 单元：`packages/solver-fem/tests/test_dry_run.py`（断言 `resultRef` + artifacts roles）
- E2E 证据：`docs/qa/Q3-冒烟记录-L2-elmer-e2e-2c1fed6.md`（`dryRun=false` / `elmerExit=0`，heat-proxy）

## 6. heat-proxy 现状 vs 磁静力学后置

| 阶段 | 求解 | 精简产物 | 可宣称 |
| --- | --- | --- | --- |
| dry-run（`MO_FEM_DRY_RUN=1`） | 不调 Elmer | fixture/stub glTF+PNG+scalars | 仅调度/契约 |
| heat-proxy E2E（`=0`，tip `2c1fed6`+） | gmsh→ElmerGrid→ElmerSolver（热方程矩形/盒子） | 同上布局；`dryRun=false`；VTU 留在 `jobs/.../solve/` **不**进默认浏览器路径 | **调度链 PASS**；**非**电机精度 |
| 磁静力学（后置） | 真 B/A 场 + 材料/绕组 BC | thinning 需从场切片生成真 glTF；`torqueNm` 等来自后处理 | 校准前仍 **禁止 ≤3%** |

Q3 出口对 F1：**文档 + thinning 写出雏形 + `/field` 可吃三件套** 即满足「切片/精简有文档与实现雏形」。真场可视化增强不阻塞本条。
