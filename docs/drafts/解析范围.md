## 3. 算法边界

### 3.1 径向 MEC（Q1 初版 / Q2 加固）
- 输入：几何摘要、材料、工况
- 输出：转矩、反电势要点、损耗粗算、电感粗估
- 实现：串联单极路径 + 解析 μ(B) 迭代；**固定 tol/max_iter，禁止随机** → 同 fixture 物理量可复现
- BLDC：同 SPM 磁路 + 方波系数近似（`meta.bldc_approx`）；完整梯形反电势下一步

### 3.2 ACIM 稳态等效电路（Q2）
- 经典单笼 T 型：Rs, Rr', Xm, Xσs, Xσr'（几何摘要 + 材料估算）
- 工况：`speed_rpm` + `voltage_v_peak`（或电流反推）；slip / freq 可算可给
- 输出：转矩、定/转子铜损、铁损粗算、电流/功率因数；`meta.solver=acim_equiv`；`losses_w.rotor_bar` 必填
- `back_emf_v_peak` 槽位 = 气隙/感应电压峰值

### 3.3 材料适配（Q2）
- `materials_adapter.py`：内联字段优先 → catalog id meta → 本地 seed → 工程默认 + `meta.note`
- 期望后端 meta 键：`docs/drafts/材料消费字段.md`（钢/磁/线圈/导条）

### 3.4 轴向多平面（Q3 — AF+PMSM MVP）
- 盘式气隙沿径向解耦为 N 个同心圆环；每环局部串联 MEC（复用 `radial_mec.network` μ(B) 迭代）；叠加磁链 → 转矩 / 反电势 / 损耗
- 几何映射（与 FE stub 对齐）：`rotor_od_m`=外径，`stator_id_m`=内径，`stack_length_m`=盘/轴向厚，`n_planes`（默认 4）；亦支持 `outer_radius_m`/`inner_radius_m`
- **MVP**：仅 `topology=AF` + `machine_type=PMSM` → `meta.solver=axial_planes`，`mock=false`；AF+BLDC/ACIM 明确报错
- **Python 金标优先**于 `packages/solver-analytic/axial_planes/`；不对标 ≤5%；golden `pending_calibration`
- FE：sync `/solver/analytic/solve` 或 Jobs `analytic` 均可；Wasm AF = stretch / fast-follow
- 不负责 Elmer/GetDP；对照字段仅与 Mo-有限元协作
- 详述：`packages/solver-analytic/axial_planes/README.md`；短草案：`docs/drafts/Q3-轴向多平面.md`
- 架构锁定 tip `8d966d9`：`docs/drafts/Q3-轴向与FEM边界.md`（快照 `solver/analytic/`；Wasm AF stretch）

### 3.5 退磁工作点（Q4-6 · 永磁）
- 输入：Br / 温漂系数或 demag 曲线要点、工况温度、工作点 B 或负载线；驱动 camelCase 工况包见 [Q4-热与退磁.md](./Q4-热与退磁.md) §2.1
- 输出：`demagMargin` + `workingPoint` (H,B) 摘要；`meta.pending_calibration`；`meta.source` ∈ {analytic,drive,fem}
- 实现：`packages/solver-analytic/thermal/demag.py`；冒烟 `smoke/run_demag_pm.py`
- **不**宣称精度；膝点缺省时工程默认 + note

### 3.6 ACIM 导条温升（Q4-6）
- 输入：导条/端环损耗（W）+ 简化热阻；可接 `acim_equiv.losses_w.rotor_bar` 或驱动 `lossesW.bar` / `endRing`
- 输出：`barDeltaT_K` / `endRingDeltaT_K`；`pending_calibration`
- 实现：`thermal/bar_temp.py`；冒烟 `smoke/run_bar_temp_acim.py`

### 3.7 简化 LPTN + 温漂闭环（Q4-7）
- 节点：copper / iron / magnet_or_bar / ambient；可配置热导/热容默认
- 闭环：节点温度 → 修正 Br / 铜阻 → 损耗缩放或再调 `solve()` → 迭代记录；`meta.converged`
- 损耗入参兼容 FEM/驱动 `lossesW` / `lossBreakdown` / `source` / `resultRef`；heat-proxy **不是** LPTN 温度
- **不**接 Elmer；`fem_compare_hook` 可空
- 实现：`thermal/lptn.py`；冒烟 `smoke/run_lptn_loop.py`

### 3.8 机型差异
| 机型 | 解析重点 | 现状 |
| --- | --- | --- |
| BLDC | 方波/梯形反电势、换相转矩脉动粗估 | **同 MEC 磁路近似**；完整梯形下一步；退磁同 PMSM 路径 |
| PMSM | 正弦反电势、d-q 电感入口量 | **径向 MEC 可用**；**轴向多平面 MVP 可用**；**退磁 MVP 可用** |
| ACIM | Rs/Rr/Xm/Xσ、滑差–转矩、导条损耗 | **稳态等效电路可用**；**导条温升 MVP 可用** |
