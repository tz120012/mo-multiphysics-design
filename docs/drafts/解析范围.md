## 3. 算法边界（实现期，非 Gate0）

### 3.1 径向 MEC（Q2）
- 输入：几何摘要（槽/齿/轭/气隙/极对数等）、材料、工况
- 输出：转矩、反电势要点、损耗粗算、电感粗估
- ACIM：叠加等效电路（励磁/转子转差支路）与导条电阻估算
- 目标：单次 ≤ 2 s（Wasm）

### 3.2 轴向多平面（Q3）
- 盘式沿径向解耦为同心圆环，一维/二维混合
- 共用材料与工况接口；`topology: RF | AF`

### 3.3 机型差异
| 机型 | 解析重点 |
| --- | --- |
| BLDC | 方波/梯形反电势、换相转矩脉动粗估 |
| PMSM | 正弦反电势、d-q 电感入口量 |
| ACIM | Rs/Rr/Xm/Xσ、滑差–转矩、导条/端环损耗 |

## 4. 目录与接口

见 `packages/solver-analytic/README.md` 与 `packages/solver-analytic/api/`。

- **输入**：几何摘要 + 材料 + 工况 → `SolveRequest`
- **输出**：转矩 / 反电势 / 损耗粗算 → `SolveResult`
