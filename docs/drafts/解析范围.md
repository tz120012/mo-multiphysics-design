## 3. 算法边界

### 3.1 径向 MEC（Q1 初版 / Q2 加固）
- 输入：几何摘要、材料、工况
- 输出：转矩、反电势要点、损耗粗算、电感粗估
- 实现：串联单极路径 + 解析 μ(B) 迭代；**固定 tol/max_iter，禁止随机** → 同 fixture 物理量可复现
- BLDC：同 SPM 磁路 + 方波系数近似（`meta.bldc_approx`）；完整梯形反电势下一步

### 3.2 ACIM 稳态等效电路（Q2）
- 经典单笼 T 型：Rs, Rr', Xm, Xσs, Xσr'（几何摘要 + 材料估算）
- 工况：`speed_rpm` + `voltage_v_peak`（或电流反推）；slip / freq 可算可给
- 输出：转矩、定/转子铜损、铁损粗算、电流/功率因数；`meta.solver=acim_equiv`；`losses_w.rotor_bar` 必填
- `back_emf_v_peak` 槽位 = 气隙/感应电压峰值

### 3.3 材料适配（Q2）
- `materials_adapter.py`：内联字段优先 → catalog id meta → 本地 seed → 工程默认 + `meta.note`
- 期望后端 meta 键：`docs/drafts/材料消费字段.md`（钢/磁/线圈/导条）

### 3.4 轴向多平面（Q3）
- 盘式沿径向解耦为同心圆环；共用材料与工况接口；`topology: AF`（契约枚举仍含 RF）
- **Python 金标优先**于 `packages/solver-analytic/axial_planes/`；机型 MVP=**PMSM**
- FE：sync `/solver/analytic/solve` 或 Jobs `analytic` 均可；Wasm AF = stretch / fast-follow
- 不负责 Elmer/GetDP；对照字段仅与 Mo-有限元协作

### 3.5 机型差异
| 机型 | 解析重点 | 现状 |
| --- | --- | --- |
| BLDC | 方波/梯形反电势、换相转矩脉动粗估 | **同 MEC 磁路近似**；完整梯形下一步 |
| PMSM | 正弦反电势、d-q 电感入口量 | **径向 MEC 可用（Q2 加固）** |
| ACIM | Rs/Rr/Xm/Xσ、滑差–转矩、导条损耗 | **稳态等效电路可用** |

见 `packages/solver-analytic/README.md` 与 `packages/solver-analytic/api/`。
