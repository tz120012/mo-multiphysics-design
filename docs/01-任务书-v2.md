## §1 背景与目标

### 1.1 背景

无人机、eVTOL、新能源汽车等场景对高功率密度、高效率电机需求迫切。径向磁通与轴向磁通（盘式）电机各具优势；现有商业电机设计软件（Ansys、JMAG 等）价格高、硬件门槛高、学习曲线陡，且缺少面向无人机工况的方波（BLDC）与正弦（PMSM/FOC）电调驱动对比，以及对 **ACIM（感应电机）** 的一等公民支持。

### 1.2 目标

打造 **云端 Web、免安装、跨平台、可协同** 的电机多物理场智能设计平台：

1. **拓扑全覆盖方向**：径向（Radial Flux, RF）+ 轴向（Axial Flux, AF）。
2. **机型一等公民**：BLDC、PMSM、**ACIM** 并列，不可降级为附属模板。
3. **双核仿真**：秒级 **解析**（MEC / 多平面 / ACIM 等效电路）+ 云端高精度 **FEM**（2D/3D，Elmer/GetDP）。
4. **无人机电调特色**：方波 / FOC / V/f + 感应 FOC 同屏对比，含 PWM、死区、效率 Map、转矩脉动、损耗分离、退磁（永磁）与导条温升（ACIM）。
5. **多物理场与优化**：热–力耦合 + NSGA-II 多目标寻优。
6. **教学可讲清（产品原则）**：商用对标 **ANSYS Maxwell**；参考其能力，但步骤须更精细、可解释（每步可讲清，不只结果）；UI/流程/报告按「可演示 + 可讲清」拆。细则见 [03 §1.1](03-用户故事与MVP.md)。**不**据此扩大 MVP 矩阵；重大范围仍报 Motor。

## §2 拓扑 × 机型矩阵

| 拓扑 \\ 机型 | BLDC | PMSM | ACIM |
| --- | --- | --- | --- |
| **径向 RF** | MVP 全流程 | MVP 全流程 | MVP 全流程 |
| **轴向 AF** | 随后 | MVP 全流程 | 随后 |

- **MVP 范围**：径向三种机型（BLDC / PMSM / ACIM）全流程 + 轴向 PMSM 全流程。
- **随后**：轴向 BLDC、轴向 ACIM（在 MVP 验收后排期）。
- 「全流程」指：参数化几何 → 解析初选 → FEM 校核 → 驱动/后处理 →（可选）热–力与优化。

## §3 四大模块

### 模块一：云端底座与参数化几何

- 账号与项目管理；标准 **`.mems`** 工程包（结构化 JSON + 二进制结果缓存）；命令模式 Undo/Redo 历史树。
- 材料库：硅钢（B-P 拟合）、永磁（退磁曲线与温漂）、线圈；**ACIM 导条材料与导条几何**（槽形、导条截面、端环）为一等参数。
- 径向几何：内/外转子，槽形（直/斜/扇形）、齿轭、磁钢拓扑。
- 轴向几何：单定双转（RFMR）、双定单转（FRMF）等；内外径、盘数等径向变化参数。
- CAD 导出：STEP / DXF。

### 模块二：解析求解（MEC + 多平面 + ACIM 等效电路）

- **径向**：非线性磁路法（MEC），秒级方案初选；客户端 Wasm 或轻量后台。
- **轴向**：多平面二维展开积分，沿径向解耦为同心圆环，一维/二维混合快速解析。
- **ACIM**：稳态/准稳态 **等效电路**（定子/转子阻抗、励磁支路、转差），与几何/材料参数联动；支持导条集肤与端环修正的工程近似。

### 模块三：FEM（2D/3D Elmer / GetDP）

- **径向**：以 2D 为主、3D 为辅；多线程/多进程并行。
- **轴向**：3D 网格与求解为主，云端 HPC / Celery 调度。
- 内核锁定：**Elmer / GetDP**；自动前处理、网格、求解、场量后处理回传。

### 模块四：驱动、后处理、热–力耦合与优化

**驱动：**

| 机型 | 驱动模式 |
| --- | --- |
| BLDC | 方波电流源 / 方波电调 |
| PMSM | FOC（正弦） |
| ACIM | V/f + 感应 FOC |

共性能力：

- PWM 斩波与开关频率、逆变器 **死区（Dead time）** 对电流畸变的影响。
- **效率 Map**；**同屏对比** 转矩脉动（Torque Ripple）、震动/噪声倾向。
- 损耗分离：铁损、铜损、永磁涡流（若适用）、导条/端环损耗（ACIM）。
- **退磁**工作点（永磁机型，高温/过载）；**导条温升**（ACIM）。

**热–力与优化：**

- 场–路–热闭环：电磁损耗 → LPTN 热网 → 稳态/瞬态温度 → 反馈修正剩磁温漂与电阻。
- 轴向专项：单边磁拉力、盘面变形与轴承载荷评估。
- **NSGA-II**：效率、成本、转矩脉动等为多目标自动寻优。

## §5 里程碑（Q1–Q4）与误差阈值

整体约 12 个月：

```
【Q1 架构与几何】→【Q2 径向与解析】→【Q3 轴向与 FEM】→【Q4 驱动联调与优化】
```

| 季度 | 主题 | 关键交付 |
| --- | --- | --- |
| **Q1**（1–3 月） | 云端架构、工程管理、几何引擎 | 前后端骨架；`.mems` 规范；Three.js 径向+轴向参数化建模与 Undo/Redo |
| **Q2**（4–6 月） | 解析求解器与径向全流程 | 材料库 + MEC + ACIM 等效电路；径向 BLDC/PMSM/ACIM 跑通；Benchmark |
| **Q3**（7–9 月） | 轴向与云端 FEM | 多平面解析；轴向 PMSM；Elmer/GetDP 调度与 2D/3D 校核链路 |
| **Q4**（10–12 月） | 驱动、热–力、优化、联调 | 方波/FOC/V/f+感应 FOC；同屏对比；热闭环；NSGA-II；压测与私有化路径 |

**误差阈值（待校准，正式数以标定报告为准）：**

- 解析相对标杆：**≤ 5%**
- FEM 相对标杆：**≤ 3%**

未完成标杆用例与校准流程前，不得宣称达到上述阈值。

## §6 `.mems` 工程包大纲

`.mems` 为压缩工程包（建议 zip 容器），至少包含：

```
project.json          # 元数据：名称、版本、拓扑、机型、单位制、创建/修改时间
geometry/             # 参数化几何与拓扑描述（JSON）
materials/            # 材料引用与自定义曲线
solver/
  analytic/           # 解析输入/输出快照
  fem/                # FEM 工况、网格句柄、结果索引
drive/                # 电调与驱动工况定义
results/              # 二进制缓存（场量切片、效率 Map、波形等）
history/              # Undo/Redo 命令树摘要
manifest.json         # 文件清单与校验和
```

版本字段须与任务书 / 门禁文档中的 schema 版本对齐；破坏性变更走 Gate 评审。

## §7 风险

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| **渲染与大数据** | 轴向 3D FEM 网格与场数据量大，易卡顿 | 服务端切片/等值面精简；WebGPU；按需流式加载 |
| **私有化** | 工业客户顾虑方案上云 | 公有云 SaaS + 企业私有化（On-Premise）双轨 |
| **ACIM 复杂度** | 导条几何、集肤、端环、感应 FOC 与温升耦合难于永磁机 | ACIM 专属材料/几何一等参数；等效电路先行；FEM 与温升分阶段验收；不挤占 MVP 永磁路径 |

## §8 变更说明（相对 v1）

1. **产品命名与文档体系**：正式代号 **Mo**；任务书升至 **v2.0**；配套《阶段任务拆解与门禁》。
2. **ACIM 一等公民**：由「未覆盖/附属」提升为与 BLDC/PMSM 并列；径向 ACIM 纳入 MVP；补充导条材料/几何、等效电路、V/f + 感应 FOC、导条温升。
3. **拓扑 × 机型矩阵明确**：MVP = 径向三种全流程 + 轴向 PMSM；轴向 BLDC/ACIM 随后。
4. **技术栈锁定**：前端明确为 **Vue 3 + TS + Element Plus + Three.js**（v1 为 React/Vue、Three/Babylon 未锁）；后端补齐 **Redis + PostgreSQL**；FEM 明确 Elmer/GetDP。
5. **驱动表述修正**：v1「定量计算并**定理**对比转矩脉动」更正为「**同屏**对比转矩脉动」——强调 UI 同屏对照，而非「定理」。
6. **误差阈值**：解析 ≤5% / FEM ≤3% 写入任务书，标注「待校准」。
7. **门禁与隔离**：引入 Gate0→Q4；仓库独立于 `low-altitude-platform` 等其他项目。
8. **重建说明**：2026-10-28 因环境恢复，自 `/workspace/mo-platform` 从零重建文档与骨架；业务代码仍须 Gate0 签字后方可开始。
