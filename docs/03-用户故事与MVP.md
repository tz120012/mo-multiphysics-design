## 1. 愿景

云端 Web、免安装：完成径向 / 轴向电机参数化设计、秒级解析初选与云端 FEM 校核，并同屏对比方波 / FOC / V/f+感应 FOC 驱动效果。

## 1.1 产品原则（教学可讲清）

> **用户确认（Motor 转述 · 2026-10-28）**：商用对标 **ANSYS Maxwell**；功能可参考其能力，但本产品有**教学任务**——步骤须**更精细、可解释**（每步可讲清，不只给结果）。

| 原则 | 含义 | 落地 |
| --- | --- | --- |
| **可参考商用** | 能力对标 **ANSYS Maxwell**（几何→激励/材料→求解→场/力后处理等能力面） | 参考能力，**不**照搬黑盒；教学向步骤更精细、可解释 |
| **教学优先** | 每一步都能讲清「输入 → 假设/模型 → 中间量 → 结果」 | UI/向导/报告按步骤拆分，保留中间态与口径说明 |
| **可演示 + 可讲清** | 演示能跑通；讲解能指着屏幕说清公式/边界/降级 | 后续 UI、流程、报告拆项时双检：能演示？能讲清？ |
| **范围纪律** | 本原则**不**扩大 MVP 矩阵、**不**改误差硬门槛 | 重大范围变更仍报 Motor；**不开宣称 MVP 已达成** |

**不适用**：把「可讲清」当成宣称解析 ≤5% / FEM ≤3% 或 MVP 已达成的替代。误差与 MVP 仍以 Q5 / Motor 签字为准。

## 2. 拓扑 × 机型（与任务书一致）

| 拓扑 \\ 机型 | BLDC | PMSM | ACIM |
| --- | --- | --- | --- |
| **径向 RF** | MVP 全流程 | MVP 全流程 | MVP 全流程 |
| **轴向 AF** | 随后 | MVP 全流程 | 随后 |

**MVP** = 径向三种机型全流程 + 轴向 PMSM 全流程。  
**v1.0.0 / 宣称 MVP 已达成**：须经 **Q5**（误差关闭与真磁静力学）全关并由 Motor 签字后方可；硬项含解析 ≤5%、FEM 磁静力学 ≤3%、真磁静力学后处理（关 Q3-L4 整行）。完成前**禁止**宣称 MVP / 打 tag。见 [Q5-验收跟踪](qa/Q5-验收跟踪.md)。  
「全流程」= 参数化几何 → 解析初选 → FEM 校核 → 驱动/后处理 →（可选）热–力与优化。  
轴向 BLDC / ACIM：MVP 验收后排期。

## 4. 非目标

- 不宣称已达解析≤5%/FEM≤3%，除非标定报告关闭。  
- 不传输未精简超大 3D 原始场数据到浏览器。  
- 不擅自缩减 MVP 矩阵或替换锁定技术栈（须回写 01 并经 Motor）。  
- 产品角色不擅自改核心求解算法代码。  
- 禁止触碰 `low-altitude-platform` 等其他路径。
- 不以「可讲清 / 可演示」替代误差门禁或 MVP 签字。
